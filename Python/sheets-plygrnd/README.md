# Python's uv setup (virtual environment)

1. install `uv`
2. create a virtual environment using `uv`
   1. `uv venv .venv`
3. activate virtual environment `source .venv/bin/activate`
4. installer dependencies `uv sync`

# Prerequsits:

- python3
- uv
- Google cloud account
- Google cloud project with service account
- invite the service account to the google sheet, easiest is to just invite/add service account through email.
